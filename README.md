# kaspi-xml

Публичные прайс-листы для Kaspi. Файлы в этом репозитории собираются
автоматически, руками их править не нужно — правки затрёт следующая сборка.

| Файл | Кабинет | Что внутри |
|---|---|---|
| `centersna.xml` | Centersna | только матрасы |
| `matras.xml` | 30378397 | всё кроме матрасов |

Ссылки для кабинетов Kaspi:

```
https://r1kse.github.io/kaspi-xml/centersna.xml
https://r1kse.github.io/kaspi-xml/matras.xml
```

Здесь нет ни кода, ни настроек, ни ключей: сборка живёт в приватном
репозитории и присылает сюда только готовые XML.
